# 🚀 AI Excel 数据分析助手

> **解决Excel函数入门高门槛，让数据分析变得简单高效**

一个专为中小企业打造的智能Excel数据分析平台，通过**智能场景识别 + 精准提示词工程 + SQL增强可视化**，让任何人都能轻松进行专业级数据分析。

## � **为解决的核心痛点**

### 🎯 **Excel函数学习门槛高**
- **传统方式**：需要掌握复杂的Excel函数、透视表、图表制作
- **我们的方案**：上传Excel → AI自动分析 → 一键生成专业报告

### 📊 **数据分析效率低**
- **传统方式**：手工制作图表，容易出错，分析浅显
- **我们的方案**：智能识别业务场景，生成专业级分析洞察

### 🏢 **中小企业分析能力不足**
- **传统方式**：缺乏专业数据分析师，依赖外包成本高
- **我们的方案**：AI扮演15年经验分析专家，提供企业级分析能力

## ✨ **核心技术优势**

### 🧠 **智能场景识别系统**
```
Excel数据 → 多维度特征分析 → 自动识别业务场景
电商销售 | 汽车销售 | 财务分析 | 市场研究 | 运营分析
```
- **自动匹配**：基于字段名称、数据类型、内容特征智能识别
- **置信度评估**：量化场景匹配准确性，确保分析针对性
- **专业模板**：每个场景都有专门的分析角度和关注重点

### 🎯 **精准提示词工程**
```
普通AI调用：
"请分析这个Excel数据" → 得到泛化、模糊的结果

我们的提示词工程：
"你是15年电商分析专家，基于销售数据进行品牌竞争格局分析，
重点关注市场份额、价格策略、增长机会，输出排行榜数据..." 
→ 得到专业、具体的商业洞察
```

### 🚀 **SQL增强可视化引擎**
```
AI可视化建议 → 智能SQL生成 → 数据库级精准计算 → 专业图表展示
```
- **智能识别展示方式**：根据标题关键词选择最佳分析方法
- **专业业务指标**：自动计算排名、市场份额、增长率、相关性
- **数据质量保证**：SQL级别的数据验证和异常值过滤

## 🛠 **技术架构**

### 🧠 **智能分析引擎**
```
Excel文件 → 场景识别 → 提示词生成 → AI分析 → SQL增强 → 专业可视化
    ↓         ↓          ↓         ↓        ↓         ↓
  数据解析   业务场景    专家角色   深度洞察  精准计算   图表展示
```

### 🔧 **核心技术组件**
- **智能场景匹配器** (`intelligent_scenario_matcher.py`)
  - 多维度特征提取和相似度计算
  - 支持电商、汽车、财务、市场研究等场景
  
- **场景化提示词引擎** (`scenario_prompt_engine.py`)
  - 专业角色定义和分析指令生成
  - 结构化输出控制和质量保证
  
- **SQL增强分析引擎** (`sql_generator.py`)
  - AI建议智能转换为SQL查询
  - 专业业务指标自动计算

### 💻 **技术栈**
- **后端**：Python Flask + Pandas + SQLite + Gemini AI
- **前端**：React + Ant Design + ECharts
- **AI模型**：Gemini 2.0 Flash (主力) + GPT_OSS 120B (备用)

## 🚀 **快速开始**

### 环境要求
- Python 3.8+
- Node.js 14+
- Gemini API密钥

### 一键部署
```bash
# 1. 克隆项目
git clone <repository-url>
cd AI_Excel

# 2. 后端部署
cd backend
pip install -r requirements.txt
# 配置API密钥到 enhanced_analysis_api.py
python app.py

# 3. 前端部署
cd ../frontend
npm install
npm start

# 4. 访问应用
# http://localhost:3000
```
