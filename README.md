# 🚀 AI Excel 数据分析助手

> **🎯 核心理念：不是简单调用大模型，而是通过智能提示词工程充分释放AI潜力**

一个基于**智能提示词工程**的Excel数据分析平台，通过**场景识别 + 精准提示词 + 多模型协同**的创新架构，让AI扮演15年经验的行业专家，提供远超直接调用的专业分析效果。

## 🔥 **为什么我们的方案更强？**

```
❌ 传统方案：直接调用大模型
"请分析这个Excel数据" → 泛化结果、通用建议、缺乏深度

✅ 我们的方案：智能提示词工程  
"你是15年电商分析专家，基于销售数据进行品牌竞争格局分析，
重点关注市场份额、价格策略、增长机会，输出排行榜数据..." 
→ 专业洞察、具体数据、可执行建议
```

**支持模型**：Gemini 2.0 Flash (主力) + GPT_OSS 120B (备用) + 智能切换

## 🎯 核心竞争优势

### 💡 **智能提示词工程** - 项目核心特色
> **为什么不直接让大模型分析数据？**
> 
> 直接调用大模型分析数据往往得到泛化、模糊的结果。我们的创新在于：
> - **场景感知**：自动识别数据的业务场景（电商、汽车、财务等）
> - **精准提示词**：为每个场景生成专业化、结构化的提示词
> - **角色定位**：让AI扮演15年经验的行业专家，而非通用分析师
> - **输出控制**：严格定义输出格式和分析深度，确保结果的专业性

### 🧠 **三层智能架构**
```
数据输入 → 场景识别引擎 → 提示词生成引擎 → 大模型分析 → 结构化输出
    ↓           ↓              ↓            ↓          ↓
  Excel文件   业务场景匹配    专业提示词     Gemini/GPT   可视化建议
```

### 🎨 **多模型支持策略**
- **主力模型**：Google Gemini 2.0 Flash（最新、最强）
- **备用模型**：GPT_OSS 120B（开源、稳定）
- **智能切换**：根据可用性和场景复杂度自动选择最优模型
- **提示词适配**：针对不同模型特点优化提示词结构

## 🚀 快速开始

### 环境要求
- Python 3.8+
- Node.js 14+
- Google Gemini API密钥

### 后端部署

```bash
# 1. 进入后端目录
cd backend

# 2. 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 配置API密钥（在enhanced_analysis_api.py中）
# self.api_key = "your_gemini_api_key_here"

# 5. 启动服务
python app.py
```

### 前端部署

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm start
```

### 🎯 **智能模型选择策略**
```python
def select_optimal_model(self, data_complexity, scenario_type):
    """根据数据复杂度和场景类型选择最优模型"""
    if self.primary_model_available and data_complexity > 0.7:
        return self.primary_model  # 复杂分析用Gemini
    elif self.backup_model_available:
        return self.backup_model   # 标准分析用GPT_OSS
    else:
        return self.fallback_local_analysis()  # 本地分析兜底
```
